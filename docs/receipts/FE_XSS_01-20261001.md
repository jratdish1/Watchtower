# FE-XSS-01 — Glass Pane stored-XSS fix (receipt)

**Stamp:** 2026-10-01 PT · Claude Opus (primary brain, FAILOVER_ACTIVE)
**Base main:** `031f802074328a6ae3d59139cd836cd29af6eff2` (WT#4 FE states merged)
**Scope:** `frontend/watchtower.html` + zero-dependency guard test. No backend, no deploy, no secrets.

## Finding (pre-existing, inherited from upstream `16ea815c…`; not introduced by WT#4)

Agent- and API-supplied fields were interpolated raw into `innerHTML` and into inline
`onclick` / `onchange` JavaScript strings:

| Sink | Untrusted source |
|------|------------------|
| Threat matrix card + stream entry | `event.title`, `event.file_path`, `event.source`, `event.ai_verdict`, `ai_reason` |
| C2 buttons (`issueCommand('…','${file_path}','${source}')`) | FIM file path = **filename on any monitored host** |
| Deep-inspect modal | whole event incl. `JSON.stringify(event)` |
| Mesh panel / matrix title / empty state | host id (beacon `host` param) |
| Inventory | `app.name`, `app.user`, `app.host`, `app.hash` (inline clipboard handler) |
| Topology | switch names from SSH scan |
| OTA select / policy host list | group names, host ids (inline `reassignHost('${host}')`) |

**Impact:** anyone able to create a file on a monitored endpoint (or holding the shared
agent key) could run script in the operator console, read the injected API key, and issue
fleet-wide C2 (`kill`, `quarantine`, `lock_dir`) or OTA. Severity: **High**.

## Fix

1. `escHtml()` helper (`& < > " ' \``) applied to every data interpolation in HTML templates.
2. All data-built inline handlers removed; replaced with `data-*` attributes + `addEventListener`
   closures that pass the **raw** value (C2 target/host and copied hash are byte-exact, not
   double-escaped).
3. Policy host list rebuilt per row with `appendChild` (the old `innerHTML +=` loop would
   have destroyed bound listeners).
